About the learning design

This game uses short retrieval attempts, immediate explanatory feedback, mixed practice, and adaptive resurfacing of missed concepts. Progress is saved only in this browser with localStorage.

  • Retrieval practice: answering from memory strengthens delayed retention more effectively than rereading alone. Roediger & Karpicke (2006)
  • Practice testing and spacing: both are rated high-utility learning techniques. Dunlosky et al. (2013)
  • Corrective feedback: explanations after testing help repair misconceptions and stabilize uncertain knowledge. Butler, Karpicke & Roediger (2008)
  • Technical grounding: questions and explanations were checked against Reliable Transmission, Encoding, Framing, and Error Detection from Computer Networks: A Systems Approach.

The game prioritizes missed concepts, but its answer explanations—not points or streaks—are the main learning tool.

Built as a dependency-free static study game: HTML, CSS, and JavaScript only.
